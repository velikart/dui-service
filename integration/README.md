# dui-service-integration (library)

## Назначение
`dui-service-integration` — библиотека интеграций (мапперы, DTO и REST-контроллеры интеграционного слоя), используемая сервисом `dui-service` для взаимодействия со сервисами заинтегрированными с DUI.

## Как подключить

### В multi-module Gradle проекте

```gradle
implementation project(":dui-service-integration")
```

### В внешнем проекте
Подключите опубликованный артефакт `dui-service-integration` из вашего Nexus/репозитория артефактов.

## Переменные окружения
Сам модуль как библиотека не требует обязательных переменных окружения.

Если в приложении активируется его web/integration функциональность, обычно нужны настройки URL внешних сервисов (например, `PRINT_SERVICE_URL`) на уровне конечного приложения.
