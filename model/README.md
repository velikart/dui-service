# dui-service-model (library)

## Назначение
`dui-service-model` — библиотека общих моделей/DTO для `dui-service` и связанных модулей для интеграции с интерфейсами на DUI.

## Как подключить

### В multi-module Gradle проекте

```gradle
implementation project(":dui-service-model")
```

### В внешнем проекте
Подключите опубликованный артефакт `dui-service-model` из вашего Nexus/репозитория артефактов.

## Переменные окружения
Для использования как библиотеки дополнительные переменные окружения не требуются.
