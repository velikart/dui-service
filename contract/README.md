# dui-service-contract (library)

## Назначение
`dui-service-contract` — библиотека контрактов API `dui-service` (OpenAPI-ориентированный модуль), которую используют сервер для имплементации Api first.

## Как подключить

### В multi-module Gradle проекте

```gradle
api project(":dui-service-contract")
```

### В внешнем проекте
Подключите опубликованный артефакт `dui-service-contract` из вашего Nexus/репозитория артефактов.

## Переменные окружения
Для использования как библиотеки дополнительные переменные окружения не требуются.
