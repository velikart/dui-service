# getPageManifest

Возвращает page manifest по `pageId` или `pageName` (в зависимости от реализации сервиса).

## Когда использовать
- Нужно получить текущее состояние manifest страницы перед редактированием.

## Входные параметры
- `pageId` / `pageName` — идентификатор страницы.

## Результат
- JSON manifest страницы.

## Ошибки
- `BAD_REQUEST` при невалидных параметрах.
- `NOT_FOUND` если страница не найдена.
