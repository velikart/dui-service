# getCollectionManifest

Возвращает полный манифест коллекции по её UUID.

## Параметры

- `collectionUUID` *(UUID, обязательно)* — идентификатор коллекции.

## Возвращает

Объект `CollectionDto` с содержимым коллекции (страницы, моки, стили, метаданные).

## Когда использовать

- Когда нужно прочитать актуальное состояние коллекции перед изменением.
- Когда нужно экспортировать/проанализировать структуру коллекции.
