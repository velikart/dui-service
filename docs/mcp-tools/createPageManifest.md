# createPageManifest

Создаёт новый page manifest для новой страницы.

## Когда использовать
- При создании новой страницы в Dynamic UI.

## Входные параметры
- `name` / `title` / `userId` (в зависимости от реализации сервиса).
- Начальные данные manifest (опционально).

## Результат
- Созданный manifest с идентификатором страницы.

## Ошибки
- `BAD_REQUEST` при невалидных входных данных.
- `CONFLICT` если страница с таким именем уже существует.
