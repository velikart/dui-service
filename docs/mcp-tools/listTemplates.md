# listTemplates

Возвращает список шаблонов страниц.

## Параметры

- `type` *(TemplateFilterDto.TypeEnum, опционально)* — фильтр по типу шаблона.

## Возвращает

Список объектов `TemplateDto`.

## Когда использовать

- Для выбора шаблона перед чтением JSON/изображения.
- Для построения каталога шаблонов.
