# getPageInstructions

Возвращает JSON-инструкцию страницы по системному имени страницы.

## Параметры

- `pageName` *(String, обязательно)* — системное имя страницы.

## Возвращает

JSON-строку с инструкцией страницы.

## Когда использовать

- Для анализа структуры страницы.
- Для автоматизированных изменений UI-конфигурации.
