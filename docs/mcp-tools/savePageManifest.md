# savePageManifest

Сохраняет обновлённый page manifest для существующей страницы.

## Когда использовать
- После изменения структуры/метаданных страницы в редакторе.

## Входные параметры
- `pageId` / `pageName` — идентификатор страницы.
- `manifest` — новое содержимое manifest (JSON).

## Результат
- Обновлённый manifest или подтверждение успешного сохранения.

## Ошибки
- `BAD_REQUEST` при невалидном JSON или параметрах.
- `NOT_FOUND` если страница не найдена.
