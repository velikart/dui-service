# listCollections

Возвращает список коллекций администратора.

## Параметры

- `userId` *(опционально)* — идентификатор пользователя-администратора.

## Возвращает

Массив объектов с полями:
- `uuid` — UUID коллекции;
- `title` — название коллекции.

## Ошибки

- `IllegalArgumentException`, если `userId` не передан и не может быть определён.
