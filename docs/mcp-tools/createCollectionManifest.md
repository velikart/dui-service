# createCollectionManifest

Создаёт новую коллекцию для указанного пользователя.

## Параметры

- `userId` *(String, обязательно)* — идентификатор пользователя-владельца.
- `collectionDto` *(CollectionDto, обязательно)* — манифест новой коллекции.

## Возвращает

Созданный объект `CollectionDto`.

## Когда использовать

- Для первичного создания коллекции.
- Для клонирования/загрузки новой структуры в систему.
