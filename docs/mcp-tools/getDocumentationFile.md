# getDocumentationFile

Читает и возвращает содержимое файла документации из папки `dui/instruction`.

## Параметры

- `fileName` *(String, обязательно)* — имя файла из папки документации.

## Возвращает

Текстовое содержимое файла (UTF-8).

## Когда использовать

- Когда нужно получить схему, инструкцию или справку для генерации/валидации UI-конфига.
