# saveCollectionManifest

Сохраняет обновлённый манифест существующей коллекции.

## Параметры

- `collectionUUID` *(UUID, обязательно)* — идентификатор коллекции для обновления.
- `collectionDto` *(CollectionDto, обязательно)* — новый манифест коллекции.

## Возвращает

Обновлённый объект `CollectionDto`.

## Когда использовать

- После правок структуры/контента коллекции.
- Для сохранения изменений, внесённых через MCP-инструменты.
